## 사용 방법

PDF는 내려받아 인쇄하거나 PDF 앱의 주석·펜 기능으로 필기합니다. PDF 안의 필기칸은 입력 양식이 아닌 필기용 공간입니다.

Markdown 파일은 GitHub에서 열어 읽고 편집할 수 있습니다. 예상 문답은 접힌 모범답안을 펼쳐 확인합니다.

웹 학습 화면은 GitHub Pages로 배포할 수 있습니다. 태블릿 브라우저에서 배포 주소를 열면 마인드맵·예상 문답·필기를 사용할 수 있습니다. PDF 열기 버튼으로 PDF 앱에서도 학습할 수 있습니다. GitHub 파일 목록의 HTML은 사이트 실행 화면이 아니라 소스 보기입니다.

## 필기 저장

HTML 화면의 필기는 해당 브라우저에 저장됩니다. GitHub 저장소나 다른 기기로 자동 동기화되지 않습니다. ‘내 필기 백업’으로 JSON 파일을 저장하고, 다른 기기의 ‘필기 백업·복원 사용법’에서 그 파일을 복원할 수 있습니다. 복원은 해당 기기의 필기를 교체하므로 먼저 백업하세요. ‘전체 요약과 내 노트 모아 보기’에서는 텍스트로도 복사할 수 있습니다. 브라우저 데이터를 지우면 필기가 없어질 수 있습니다.
